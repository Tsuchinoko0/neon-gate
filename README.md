# NEON GATE

脳のスペックで、住める場所が決まる街。

[脳スペック診断](https://tsuchinoko0.github.io/brain-spec/)の続編となる、サイバーパンク世界のドット絵ブラウザゲームです。東京の外「圏外」から、自分の脳のスペックを上げて東京の中心を目指します。

**▶ 遊ぶ：https://tsuchinoko0.github.io/neon-gate/**

## どんなゲーム？

1. 闇医者のところで「ブレインスキャン」を受け、自分の脳のスペックを測る
2. 情報屋のミナから仕事（ミニゲーム）をもらい、クレジットを稼ぎながらスペックを上げる
3. 検問ゲートを通って、東京の中心へ近づいていく。中心に近いほど街は明るくなる

ブレインスキャンは脳をパソコンに見立てて、4つのパーツを測ります。

| パーツ | 脳の機能 | 鍛える仕事 |
| --- | --- | --- |
| CPU | 反応速度 | ドローン回避：照準線が出た列から逃げる |
| RAM | 短期記憶 | パスコード侵入：光った順にキーを押す |
| GPU | 色の識別 | 監視カメラ解析：群衆から指定の色の人を探す |
| ALU | 暗算 | 暗号ロック解除：□に入る数を答える |

スペックの上げ方は2通りあります。ミニゲームで本人の実力を鍛える「生身」の道と、稼いだお金でインプラントを入れる「拡張」の道。どちらを選ぶかで、街の人たちの反応や物語の結末が変わります。

難易度はスキャン結果から自動で決まり、設定でいつでも変えられます。難しいほど仕事の報酬が増えます（EASY ×0.8／NORMAL ×1／HARD ×1.25）。最初からスペックが高い人でも楽しめるよう、ゲートは「最初のスキャンからどれだけ伸びたか」で判定します。

## 操作方法

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ↑↓←→ または WASD | 十字ボタン |
| 走る | Shift を押しながら移動 | 「走る」ボタン（押すたびに切り替え） |
| 話す・進める | Space・Enter・Z | 話す ボタン |
| ライト | F | 上の「持ち物」 |

## 脳スペック診断の記録を使う

同じブラウザで先に[脳スペック診断](https://tsuchinoko0.github.io/brain-spec/)を受けていれば、その記録をゲームのスキャン結果として読み込めます（設定画面、または闇医者との会話から）。

## 技術メモ

HTML・CSS・JavaScript だけで作っていて、外部ライブラリは使っていません。音は Web Audio API でその場で鳴らしています（sound.js、音声ファイルなし）。セーブデータはブラウザ（localStorage）に保存されます。
